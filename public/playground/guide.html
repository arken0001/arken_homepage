1장

설치

Windows 10·11(64비트)에서 씁니다. 설치 파일 하나를 받아 실행하면 되고, 이후 새 판은 앱이 알아서 받습니다.

  1. 설치 파일 받기

    소개 페이지의 Windows용 다운로드를 누릅니다. 파일 이름은 Playground-버전-Setup.exe입니다.

  2. 보안 경고가 뜨면 「추가 정보 → 실행」

    아직 코드 서명을 받기 전이라 Windows가 「알 수 없는 게시자」 창을 띄웁니다. 추가 정보를 누른 뒤 실행을 누르면 이어집니다. 파일을 받은 곳이 arken.co.kr 인지만 확인해 주세요.

  3. 설치하고 실행

    설치 위치를 바꿀 필요는 없습니다. 끝나면 바탕화면과 시작 메뉴에 Playground가 생깁니다.

  4. 처음 켤 때는 2~3분 기다리기

    앱이 필요한 부품을 준비하느라 첫 실행만 오래 걸립니다. 「서버 시작 대기 중」 글자가 보이면 정상입니다. 두 번째부터는 몇 초면 뜹니다.

자동 업데이트 — 앱을 켤 때마다 새 판이 있는지 확인합니다. 새 판이 있으면 오른쪽 아래에 안내가 뜨고, 「지금 적용」을 누르면 다시 켜지면서 바뀝니다. 직접 다시 받을 필요가 없습니다.
2장

회원가입·로그인

Playground 계정은 이메일 하나로 만듭니다. 크몽 등에서 받은 초대코드가 있으면 가입할 때 넣고, 없으면 가입 뒤 요금제를 고릅니다.

  1. 첫 화면에서 「회원가입」 선택

    이메일과 비밀번호를 넣습니다. 이메일이 로그인 아이디가 됩니다.

  2. 메일로 온 6자리 숫자 넣기

    가입한 이메일로 인증번호가 옵니다. 메일이 안 보이면 스팸함을 보고, 「인증번호 다시 보내기」를 누르세요.

  3. 초대코드가 있으면 이때 넣기

    초대코드 칸에 넣으면 가입과 동시에 그 요금제로 이용이 시작됩니다. 없으면 비워 두고 넘어갑니다. (나중에 설정 → 요금제 및 결제에서도 넣을 수 있습니다)

  4. 로그인

    가입한 이메일·비밀번호로 로그인합니다. 「아이디 저장」을 켜 두면 다음부터 이메일이 채워집니다(비밀번호는 저장하지 않습니다).

PC 등록 — 이용권이 있는 계정으로 로그인하면 그 PC가 이용 기기로 등록됩니다. Basic·Pro는 1대, Premium은 2대까지 동시에 쓸 수 있습니다. PC를 바꾸는 방법은 5장에 있습니다.
비밀번호를 잊었을 때 — 로그인 화면의 비밀번호 찾기에서 이메일을 넣으면 인증번호가 오고, 새 비밀번호를 정할 수 있습니다.
3장

처음 설정 — 네이버 계정, 카페, 키워드

세 가지를 등록해 두면 모든 기능이 준비됩니다. 오른쪽 위 설정에 모여 있습니다.

3-1. 네이버 계정 등록과 로그인

카페글 품질 체크·회원 수집·글 수집·검색 순위는 네이버에 로그인된 상태에서만 됩니다. 로그인은 내 PC에서 열리는 크롬 창에서 직접 하고, 비밀번호는 잠가서 내 PC에만 보관합니다.

  1. 설정 → ID & API 설정

    왼쪽 「네이버 계정」 칸에 아이디와 비밀번호를 넣고 추가를 누릅니다. 계정은 여러 개 넣을 수 있습니다.

  2. 오른쪽 「네이버 로그인」에서 「로그인」

    크롬 창이 뜹니다. 그 창에서 평소처럼 로그인하세요. 끝나면 창이 저절로 닫히고 「로그인됨」으로 바뀝니다.

  3. 보안문자(캡차)가 뜨면 직접 풀기

    사람 확인 이미지가 나오면 그 창에서 풀면 됩니다. 풀리는 즉시 이어집니다. 창을 그냥 닫으면 몇 초 안에 「로그인 창이 닫혀 로그인을 멈췄습니다」라고 알려 줍니다.

알아 두세요 — 저장된 로그인은 24시간 뒤 만료됩니다. 왼쪽 메뉴 맨 아래 「네이버」 칸에서 지금 몇 개 계정이 로그인돼 있는지 늘 볼 수 있고, 만료되면 여기서 다시 로그인하면 됩니다. 한 번에 최대 3개까지 로그인할 수 있습니다.

3-2. 카페 등록

  1. 설정 → 카페 목록 관리

    「카페 정보 추출」 칸에 카페 주소(https://cafe.naver.com/카페주소)를 넣고 추출을 누릅니다.

  2. 기본 정보와 게시판이 채워지면 등록

    카페 이름·등급·회원 수·게시판 목록을 자동으로 불러옵니다. 「운영」 표시를 켜 두면 전체 카페 현황에 나옵니다.

  3. 사용할 네이버 계정 연결

    카페마다 어느 네이버 계정으로 수집할지 고릅니다. 그 카페의 매니저·스탭 계정을 쓰면 회원 수집까지 됩니다.

3-3. 노출 키워드 등록

  1. 설정 → 노출 키워드 관리

    카페를 고르고 지켜볼 키워드를 넣습니다. 「카페글 노출 순위」 화면 안에서도 넣을 수 있습니다.

  2. 등록하면 기록이 시작됩니다

    등록한 키워드는 매일 오전 9~10시에 순위를 자동으로 확인해 쌓습니다. 요금제마다 넣을 수 있는 키워드 수가 다릅니다(Basic 15개 · Pro 50개 · Premium 200개).

기능별 사용법

왼쪽 메뉴 순서 그대로입니다. 기능마다 네 칸으로 정리했습니다 — 언제 쓰나 · 이렇게 하세요 · 결과 읽는 법 · 알아 두세요.

전체 카페 현황

아침에 한 번, 오늘 무엇부터 할지 정할 때

이렇게 하세요

  1. 등록한 카페들이 카드로 나란히 보입니다.
  2. 전체 업데이트를 누르면 모든 카페의 최신 수치를 받아옵니다.
  3. 카드마다 기본정보 카페통계 활동내역 불량게시글 단추로 자세히 봅니다.

결과 읽는 법

  • 왼쪽 표: 이번 등급 산정 기간(보름)의 날짜별 게시글·댓글·가입·유입검색 수.
  • 가운데 표: 지난 기간들의 활동 점수와 등급. 점수가 오르는지 한눈에 봅니다.
  • 오른쪽 그래프: 등급 변화선. 나무·열매·가지… 어느 띠에 있는지 보입니다.
등급 산정 기간과 등급 발표일이 제목 아래에 적혀 있습니다. 발표일 전에는 점수만 오르고 등급은 그대로입니다.

카페글 품질 체크

쓴 글이 검색에 나오는지 확인할 때 (가장 많이 쓰는 기능)

이렇게 하세요

  1. 위 「카페」 칸에서 등록한 카페를 고르거나 주소를 넣고 게시판 불러오기.
  2. 「수집 범위」를 정합니다 — 최근 며칠치, 또는 몇 개.
  3. 수집으로 글 목록을 모은 뒤 체크를 누르면 글마다 검색 노출을 확인합니다.
  4. 오래된 글까지 보려면 기간 체크(6개월·1년).

결과 읽는 법

  • 위 숫자 칸: 전체 · 최적상태 · 정상노출 · 저품질의심 · 저품질상태 · 판단불가 · 오류.
  • 처방 브리핑: 카페 → 게시판 → 계정 → 글 순서로 어디가 문제인지 짚어 줍니다. 위에서 걸리면 아래를 고쳐도 소용없습니다.
  • 결과 표: 글마다 상태·게시판·제목·작성자·메인/카페 순위. 제목을 누르면 글이 열립니다.
  • 「계정 품질」「게시판별」 탭에서 계정별·게시판별로 묶어 봅니다.
제목이 10자 미만인 글은 확인 대상에서 빠지고 사용량에도 세지 않습니다. 결과는 엑셀 HTML로 내보내거나 「저장된 리포트」에서 다시 볼 수 있습니다.

타카페 활동 현황

내 카페가 전체에서 어디쯤인지, 같은 주제 카페들이 어떤지 볼 때

이렇게 하세요

  1. 들어가면 왼쪽 메뉴가 저절로 접혀 표가 넓게 보입니다. 처음엔 자료를 받느라 몇 초 걸립니다.
  2. 왼쪽에서 등급·키워드·지역으로 거르고, 위 「검색」에 카페 이름을 넣어 찾습니다.
  3. 표 머리글(점수·회원·전체글…)을 누르면 정렬됩니다.
  4. 줄 앞의 i(정보) 단추는 카페 소개·설립일·가입 방식을, 활동 단추는 기간별 활동표를 엽니다.
  5. 왼쪽 위 생태계를 누르면 시장 전체 그림으로 넘어갑니다.

결과 읽는 법

  • 등급·점수: 네이버 등급(씨앗~숲)과 활동 점수. 「대표」는 네이버 대표카페.
  • 회원·전체글·총방문자수: 규모. 「앱 설치수」는 카페앱 설치 수.
  • 가입 방식·가입 조건: 바로 가입인지 승인제인지.
  • 생태계 화면: 주제별 시장 지도(오른쪽일수록 카페 많음, 위일수록 회원 많음 → 왼쪽 위가 「빈 시장」), 등급 올라가는 기준(등급마다 회원 중앙값), 지역별 주제, 급성장·위험 신호.
요금제에 따라 볼 수 있는 자료 기간이 다릅니다 (Basic 4일 · Pro 14일 · Premium 30일). 자료는 새 판이 나오면 앱이 알아서 받습니다 — 화면 위 「자료 기준일」로 확인하세요.

네이버 검색 순위

「이 키워드로 검색하면 우리가 몇 번째에 나오지?」를 지금 바로 확인할 때

이렇게 하세요

  1. 오른쪽 위 「검색어 입력」에 키워드를 넣고 검색.
  2. (선택) 왼쪽 「타겟」에 내 카페를 고르거나 카페 영문주소·블로그 아이디를 넣으면 내 글에 표시가 붙습니다.
  3. 자주 보는 검색은 저장해 두고 「저장목록」에서 다시 봅니다.

결과 읽는 법

  • 통합검색의 글 칸과 카페탭 결과를 나란히 보여 줍니다.
  • 초록=카페, 파랑=블로그, 보라=인플루언서. 노란 「타겟」 표시가 내 글입니다.
  • 「대충 위쪽」이 아니라 자리 번호로 남습니다.
검색 1회가 사용량 1회입니다. 네이버 로그인이 되어 있어야 합니다.

카페글 노출 순위

내 글의 순위가 날마다 어떻게 변하는지 기록으로 볼 때

이렇게 하세요

  1. 위에서 카페를 고릅니다. 괄호 안 숫자가 등록된 키워드 수입니다.
  2. 키워드 관리 펼치기로 키워드를 넣고 뺍니다.
  3. 현재 순위 확인을 누르면 지금 순위를 바로 잽니다(키워드 10개에 약 5분). 그 밖에는 매일 오전 9~10시에 자동으로 잽니다.

결과 읽는 법

  • 날짜별 순위표: 키워드마다 최근 15일의 순위. 「통합검색 / 카페탭」 두 숫자입니다(카페탭은 50위까지). 「-」는 안 나온 것.
  • 순위 추이: 최근 30일 그래프. 위로 갈수록 좋은 순위입니다.
  • 키워드 옆 숫자는 월 검색량입니다.
키워드 개수가 사용량입니다. 순위를 올려 주는 기능이 아니라 기록하는 기능입니다.

노출 연관 키워드 발굴

메인 키워드는 경쟁이 세서 안 올라갈 때, 어떤 키워드부터 쓸지 찾을 때

이렇게 하세요

  1. 「메인 키워드 입력」에 키워드를 넣고 분석.
  2. 자동완성·「함께 많이 찾는」·연관검색어를 모아 하나씩 검색 화면을 확인합니다. 키워드가 많을수록 오래 걸립니다.
  3. 끝나면 결과를 저장해 「저장된 키워드」에서 다시 봅니다.

결과 읽는 법

  • 연관 키워드마다 「글 칸 위치」와 「카페 글 개수」가 나옵니다.
  • 노출 가능: 광고·AI 칸을 뺀 상위 3칸 안 첫 글 칸에 카페 글이 2개 이상인 키워드. 이런 키워드로 글을 먼저 올리고, 그 힘으로 메인 키워드를 노립니다.
추출 1회가 사용량 1회입니다. 네이버 로그인이 필요합니다. 순위를 올려 주는 기능이 아닙니다.

카페글 수집하기

잘 되는 카페의 글 제목·주제를 모아 참고할 때

이렇게 하세요

  1. 카페 영문주소를 넣고 게시판 불러오기, 또는 게시판 주소를 붙여 넣고 바로 가져오기.
  2. 수집 범위(전체글/인기글, 최근 며칠 또는 몇 개)를 정합니다.
  3. 순서대로 리스트 수집 → 공개글 수집 → 회원글 수집. 회원글은 그 카페에 가입된 계정으로만 됩니다.
  4. 엑셀로 내보냅니다.

결과 읽는 법

  • 글마다 상태 표시: 완료 · 우회확인 · 회원만 · 회원전용 · 없음.
  • 「회원만」은 가입해야 보이는 글, 「우회확인」은 검색을 거쳐 본문을 가져온 글입니다.
목록 수집과 본문 보기가 사용량을 따로 씁니다(위 띠에 두 숫자가 보입니다).

가입없이 카페글 보기

글 하나 확인하려고 그 카페에 가입하고 싶지 않을 때

이렇게 하세요

  1. 글 주소(https://cafe.naver.com/카페주소/글번호)를 넣고 글 열기.
  2. 주소로 못 찾으면 「제목 직접 입력」으로 제목을 넣어 다시 찾습니다.

결과 읽는 법

  • 네이버 검색에서 그 글을 찾아 들어가 본문을 보여 줍니다.
  • 못 찾으면 「검색에서 찾지 못했습니다」 — 그 글이 검색에 노출되지 않은 것입니다.
검색에 노출된 글만 볼 수 있습니다. 저품질 등으로 검색에서 빠진 글은 원리상 볼 수 없습니다. 네이버 로그인이 필요합니다.

카페 회원 수집하기

내 카페 회원 중 누가 실제로 활동하는지 볼 때

이렇게 하세요

  1. 위에서 카페 탭을 고릅니다(내가 매니저·스탭인 카페).
  2. 처음이면 전체 수집, 그 뒤로는 업데이트로 바뀐 부분만 받습니다. 회원이 많으면 시간이 걸리니 앱을 끄지 마세요.
  3. 왼쪽 메뉴의 「카페 회원 수집하기」 옆에 점이 뜨면, 지난 기간 마감 업데이트가 남은 카페가 있다는 뜻입니다.

결과 읽는 법

  • 최근 30일 가입·탈퇴 그래프와 최근 변동(신규·탈퇴·등급 변경·새 글·댓글·방문).
  • 기간 변동: 보름 단위 마감 기록.
  • 회원 목록: 등급·활동 필터로 거릅니다. 활동타입(활동회원·반짝회원·비활동회원·유령회원)이 카페의 진짜 힘을 보여 줍니다.
사용량은 명 단위입니다. 수집이 중간에 끊기면(앱 종료 등) 그 회차는 저장되지 않으니 처음부터 다시 하면 됩니다. 기존 자료는 지워지지 않습니다.

검색으로는 안 나오는 운영 노하우를 읽을 때

이렇게 하세요

  2. 오른쪽에 책처럼 펼쳐집니다. 위 띠에 지금 읽는 자리와 쪽수가 보입니다.

결과 읽는 법

  • 장마다 끝에 「실행 체크리스트」가 있습니다. 순서대로 해 보세요.
  • 새 내용은 계속 더해집니다. 제목 아래 「v8 · 갱신일」로 확인하세요.

사용량 · 요금제 · 초대코드

요금제마다 한 달에 쓸 수 있는 양이 정해져 있고, 앱이 늘 보여 줍니다.

사용량 읽는 법

일을 시키는 화면에 들어가면 오른쪽 위 설정 왼쪽에 35건(58건) 이용중처럼 보입니다. 앞 숫자가 이번 달에 쓴 양, 괄호 안이 한 달 한도입니다. 마우스를 올리면 남은 양과 다시 채워지는 날이 나옵니다.

한도를 다 쓰면 그 기능이 멈추고 「사용량을 다 썼습니다」 창이 뜹니다. 창의 요금제 업그레이드를 누르면 상위 요금제로 바로 바꿀 수 있고, 바꾸는 즉시 한도가 늘어납니다.

초대코드로 시작하고 연장하기

  1. 처음이면 가입할 때

    회원가입 화면의 「초대코드」 칸에 넣습니다. 가입과 동시에 그 요금제로 시작됩니다.

  2. 쓰던 중이면 요금제 화면에서

    「요금제 및 결제」 위쪽 초대코드 칸에 넣고 적용. 「적용했습니다 — Pro 3개월 · 이용 종료 ○○」처럼 알려 줍니다.

  3. 남은 날은 사라지지 않습니다

    이용 중에 넣으면 남은 기간 뒤에 이어 붙습니다. 다른 요금제 코드를 넣으면 그 요금제로 바뀌고, 남은 날도 새 요금제로 씁니다.

코드는 한 번만 쓸 수 있고 사용 기한이 있습니다. 「이미 사용한 코드입니다」「기한이 지난 코드입니다」가 뜨면 코드를 준 곳에 문의하세요. 코드를 여러 번 틀리면 1시간 동안 잠깁니다.

카드로 결제하기

  1. 요금제 화면에서 원하는 요금제의 단추 누르기

    브라우저에 결제 페이지가 열립니다.

  2. 앱과 같은 Playground 계정으로 로그인

    결제한 계정에 이용권이 들어가므로, 반드시 앱에서 쓰는 이메일로 로그인하세요.

  3. 결제 뒤 앱으로 돌아오기

    앱이 이용권 상태를 다시 읽습니다. 안 바뀌면 이용권 상태 새로고침을 누르세요.

크몽에서 산 이용권은 초대코드로 적용됩니다. 연장·환불은 해당 크몽 주문에서 처리됩니다.

나의 이용 현황

아바타 → 나의 이용 현황에서 로그인 이메일, 현재 요금제와 이용 종료일, 이번 달 기능별 사용량을 한 번에 봅니다. 비밀번호 변경도 여기서 합니다.

PC를 바꿀 때

이용권은 로그인한 PC에 묶입니다(Basic·Pro 1대, Premium 2대). 다른 PC에서 로그인하면 「다른 PC에서 사용 중입니다」 창이 뜨고, 지금 등록된 PC 이름과 「이번 달 교체 n/m회」가 보입니다. 이 PC로 옮기기를 누르면 이 PC로 옮겨지고 옛 PC에서는 작업이 멈춥니다.

교체 횟수는 한 달에 정해진 만큼만 됩니다. 다 쓰면 단추가 눌리지 않고, 다음 달까지 기다리거나 운영자에게 문의해야 합니다. 집·회사를 오가며 쓰려면 PC 2대가 되는 Premium이 맞습니다.

문제가 생겼을 때

자주 보는 안내문과 대처법입니다. 대부분 앱을 완전히 닫고 다시 켜면 풀립니다.

이런 말이 뜨면왜 그런가이렇게 하세요
서버 연결 실패앱 안쪽 서버가 아직 준비 중이거나 멈췄습니다.1분 기다려 보고, 그래도 그러면 앱을 완전히 닫고(작업 표시줄까지) 다시 켭니다. 처음 켤 때는 2~3분 걸립니다.
로그인 창이 닫혀 로그인을 멈췄습니다네이버 로그인 크롬 창을 닫았습니다.설정 → ID & API 설정에서 다시 로그인. 창이 뜨면 끝까지 로그인해 주세요.
사람 확인(보안문자)이 계속 뜸같은 계정으로 짧은 시간에 여러 번 로그인했을 때 네이버가 확인을 요구합니다.그 창에서 직접 풀면 이어집니다. 자주 뜨면 잠시 뒤에 다시 하세요.
로그인됨이었는데 다시 로그인하라고 함저장된 로그인은 24시간 뒤 만료됩니다.왼쪽 아래 「네이버」 칸이나 설정에서 다시 로그인합니다.
사용량을 다 썼습니다이번 달 한도에 닿았습니다.창의 요금제 업그레이드로 상위 요금제로 바꾸거나, 다음 달 채워지는 날까지 기다립니다.
검색에서 찾지 못했습니다 (가입없이 보기)그 글이 검색에 노출되지 않았습니다. 카페·게시판·글쓴이 계정 셋 중 하나가 걸린 것입니다.이 기능으로는 볼 수 없습니다. 품질 체크로 어느 단위가 걸렸는지 확인하세요.
다른 PC에서 사용 중입니다이용권의 PC 대수를 넘었습니다.창의 이 PC로 옮기기를 누릅니다. 이번 달 교체 횟수를 다 썼으면 운영자에게 문의합니다.
타카페 자료가 옛날 날짜로 보임새 판을 아직 못 받았거나, 자료 자체가 그 날짜까지입니다.앱을 다시 켜면 새 판을 확인합니다. 화면 위 「자료 기준일」이 곧 자료의 날짜입니다.
화면이 작게 보이거나 오른쪽이 비어 있음창 크기 기억이 어긋난 것입니다.앱을 완전히 닫고 다시 켭니다.
기록이 필요할 때 — 문의하실 때 「무슨 화면에서 · 무엇을 눌렀고 · 어떤 말이 떴는지」 세 가지와 화면 사진을 함께 보내 주시면 훨씬 빨리 해결됩니다.
