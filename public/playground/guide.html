PLAYGROUND GUIDE

Playground 사용법

앱 설치부터 회원가입, 네이버 계정과 카페 등록, 주요 기능 실행까지 처음 필요한 순서대로 안내합니다.

설치회원가입·로그인초기 설정주요 기능요금제·결제
01

설치

1

설치 파일 다운로드

Playground 소개 페이지에서 Windows용 다운로드를 눌러 최신 설치 파일을 받습니다.

2

설치 파일 실행

다운로드한 설치 파일을 실행하고 화면 안내에 따라 설치합니다. 설치가 끝나면 Playground를 실행합니다.

3

업데이트 확인

이후 버전은 앱을 실행할 때 자동으로 확인됩니다. 업데이트 안내가 나오면 적용한 뒤 다시 실행합니다.

Windows 보안 안내
현재 설치 파일에는 코드 서명이 적용되지 않아 보안 확인 화면이 표시될 수 있습니다. 파일 출처가 ARKEN 다운로드 페이지인지 확인한 뒤 진행해 주세요.
02

회원가입·로그인

1

계정 만들기

앱 첫 화면에서 회원가입을 선택하고 로그인에 사용할 이메일과 비밀번호를 등록합니다.

2

로그인

가입한 계정으로 로그인합니다. 유료 이용권이 적용된 계정은 로그인한 PC가 이용 기기로 등록됩니다.

03

초기 설정

1

네이버 계정 등록

상단의 설정에서 ID & API 설정을 열고 카페 운영에 사용할 네이버 계정을 등록한 뒤 로그인합니다.

2

카페 등록

설정 → 카페 목록 관리에서 운영할 카페를 등록하고 사용할 네이버 계정을 연결합니다.

3

노출 키워드 등록

순위 변화를 계속 확인하려면 설정 → 노출 키워드 관리에서 카페별 키워드를 등록합니다.

04

주요 기능 이용

전체 카페 현황등록한 카페의 상태와 주요 수치를 한눈에 확인합니다.
카페글 품질 체크카페 주소와 게시판을 선택해 게시글의 검색 노출 상태를 확인합니다.
네이버 검색 순위검색어를 입력해 통합검색과 카페 영역의 노출 위치를 확인합니다.
카페글 노출 순위등록한 키워드를 기준으로 내 게시글의 순위 변화를 이어서 확인합니다.
리랭킹 키워드 추출메인 키워드와 연결된 검색어를 수집하고 검색량을 비교해 활용할 키워드를 선별합니다.
카페글 수집하기카페와 게시판을 선택해 운영에 필요한 게시글을 수집합니다.
가입없이 카페글 보기게시글 주소를 입력해 네이버 로그인 상태에서 확인 가능한 링크를 찾습니다.
카페 회원 수집하기내 카페의 회원 목록을 수집하고 기간별 운영 자료로 관리합니다.
05

요금제·결제

1

요금제 확인

앱 오른쪽 위 계정 메뉴에서 요금제 및 결제를 열어 현재 이용권과 요금제별 제공량을 확인합니다.

2

결제 요청

앱에서 결제를 요청하면 별도 결제 페이지가 열립니다. 앱에서 사용하는 계정으로 로그인한 뒤 금액과 결제 방식을 확인하고 진행합니다.

3

이용권 확인

결제가 완료되면 앱으로 돌아와 이용권 상태를 확인합니다. 크몽에서 구매한 이용권의 결제와 환불은 해당 크몽 주문에서 처리됩니다.

Windows 10·11 64비트 환경에서 이용할 수 있습니다.
