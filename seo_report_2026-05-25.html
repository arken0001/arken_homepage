💡 분석가 종합 인사이트

  • 공통 근본 문제: 3개 사이트 모두 외부에서 접근 시 403 응답. 이는 한국 외 IP 차단 정책이거나 Cloudflare Bot Fight Mode 활성화로 추정됨. Googlebot이 한국 IP를 사용하더라도 일부 경우 차단될 수 있어 즉시 확인 필수.
  • 색인 현황: arken.co.kr = 0페이지, komoshnik.kr = 0페이지, kosnova.kr = 2페이지. 세 사이트 합산 2페이지 색인은 서비스 규모 대비 심각한 수준.
  • 기회 포인트: kosnova.kr은 "komoshnik 러시아어 한국 정착" 검색 1위 노출 확인. 이 키워드 기반으로 관련 콘텐츠 확장 시 빠른 성과 가능.
  • 경쟁사 약점 활용: russiankorea.com 등 기존 경쟁사는 UX·모바일 취약. kosnova.kr이 콘텐츠+모바일 최적화에 집중하면 6개월 내 주요 러시아어 한국 커뮤니티 키워드 공략 가능.
  • 이번 주 최우선 액션: 서버 403 문제 해결 → Google Search Console 등록 → sitemap 제출. 이 3단계가 현재 모든 SEO 노력의 선행 조건.
