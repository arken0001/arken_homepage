🚨 이번 주 핵심 개선 과제 (우선순위순)
P1
[komoshnik.kr · kosnova.kr] sitemap.xml + robots.txt 즉시 생성 및 Search Console 제출 ⚡ 4주 미처리
두 도메인 모두 robots.txt와 sitemap.xml이 없어 Googlebot/YandexBot의 크롤링이 비효율적. 각 도메인의 /robots.txt, /sitemap.xml을 생성하고 Google Search Console + Yandex.Webmaster에 수동 색인 요청. kosnova.kr은 이미 일부 페이지 색인 시작 — sitemap 제출 시 메인 페이지 색인 가속 가능.
P1
[komoshnik.kr · kosnova.kr] meta description + OG 태그 추가 ⚡ 4주 미처리
ru/ko/en 3개 언어 파일 모두 <head>에 meta description(120~160자)과 og:title, og:description, og:image 추가. 텔레그램·VK 공유 시 미리보기 없는 상태. GA 설치로 트래픽 측정은 시작됐지만 CTR 개선 불가.
예시 (RU): description="KOMOSHNIK — ваш помощник в Корее: перевод, визы, поиск жилья и работы. Бесплатно."
P1
[komoshnik.kr · kosnova.kr] canonical 태그 + hreflang 설정 ⚡ 4주 미처리
komoshnik.kr ↔ arken.co.kr/komoshnik/ 중복 콘텐츠로 구글 패널티 위험. 각 도메인에 자기 참조 canonical 설정. ru/ko/en 파일에 hreflang 상호 참조 추가 → Yandex 다국어 색인 필수.
P2
[arken.co.kr] sitemap.xml 갱신 — lastmod 업데이트 + fragment URL 제거
lastmod가 2026-03-12(7주 전)으로 고정. /ai-news/ 일일 발행 중인데 sitemap에 미반영. #about, #develop, #projects, #tech, #contact fragment URL 5개 삭제하고 실제 크롤 가능한 URL만 유지. /ai-news/ lastmod를 오늘 날짜로 갱신.
P2
[arken.co.kr] meta description 개선 — 160자 이내로 축약 + URL 텍스트 제거
현재 description 말미에 "arken.co.kr" URL이 그대로 노출되어 부자연스러운 스니펫 생성. 160자 이내로 압축하고 핵심 키워드("네이버 카페 자동화", "스마트스토어 데이터 분석")를 앞쪽에 배치.
P2
[kosnova.kr] Search Console 색인 현황 긴급 점검
"kosnova" 브랜드 검색에 처음으로 노출됨 — 색인된 URL이 메인(/ko, /ru)인지 약관 페이지(/ko/terms)인지 확인 필요. 메인 페이지가 색인 안 됐다면 URL 검사 → 색인 요청 즉시 실행.
P3
[arken.co.kr] H1 태그 키워드 강화
현재 H1: "디지털의 경계를 다시 설계합니다." — 브랜드 감성은 좋지만 핵심 키워드 없음. "네이버 카페 자동화·AI 솔루션·스마트스토어 데이터 분석" 핵심 키워드를 H1 또는 바로 아래 H2에 명시적으로 포함.
P3
[전체] Yandex.Webmaster 등록 — 러시아어권 사이트 필수
komoshnik.kr · kosnova.kr의 메인 타겟 사용자는 러시아어권. Yandex 검색은 CIS 국가에서 Google 상회. 세 도메인 모두 Yandex.Webmaster(webmaster.yandex.ru) 등록 및 sitemap 제출 필요. arken.co.kr은 Yandex 인증 메타태그만 있고 실제 등록 여부 불명확.
P3
[전체] 롱테일 콘텐츠 전략 — 브랜드 키워드 혼동 극복
"아켄"(포켓몬), "ARKEN"(조준경·시계·미술관), "코스노바"(독일 화장품)로 검색 혼동 지속. 복합 키워드로 전환: "아켄 네이버 카페 자동화", "코모쉬닉 한국 비자", "코스노바 러시아어 커뮤니티" 등. arken.co.kr /ai-news/ 포맷을 활용해 주 1~2회 정착 가이드·업무 자동화 콘텐츠 게재 권장.
